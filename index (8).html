BestAI4Me

Run a short guided session. AI judges read the answers, you confirm, and you get a verdict on which AI fits you.

1 · AIs you use

One per line, up to 10.

2 · What matters to you

Judges score 10 things on a 0 to 10 scale. Quality sliders say how much each matters. Style sliders sit between two opposites, so choosing one side means giving up the other.

3 · API connections and judges

Paste any API key. The app guesses the provider from the key format, then Detect models asks that provider for its own model list. Unknown provider? Choose Custom and paste its base URL. Works with Gemini, Anthropic and OpenAI-style APIs (most free ones are OpenAI-style). Other formats need an adapter, and some providers block browser calls (CORS). Every connection ticked “Use as a judge” joins the panel, and a judge never scores its own AI’s answer when other judges exist.

Keys stay in this browser only, never in backups. Anyone using this browser could read them, so use limited keys. Some providers block browser calls (CORS); if so, paste answers manually.
