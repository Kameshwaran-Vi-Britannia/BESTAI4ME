Personal AI evaluation lab

BestAI4Me

Compare answers from any AI services you use. Review one AI on its own or compare any number of answers head-to-head, then track your personal ratings and Elo over time.

1 · AIs you compare

Add as many AI names as you want, one per line. The six examples start selected, but you can use one AI for a solo review or select any number for a head-to-head round. There is no fixed six-AI limit.

2 · Your evaluation priorities

Weights affect the personal fit score on your dashboard. They do not change optional judge scores.

3 · API connections

Add one connection for each AI you want to call. Supported formats: Gemini, Anthropic Messages, and OpenAI-compatible chat completions (with a configurable base URL). Give each profile the same name as an AI in your list; its Generate button will appear in that answer box.

Keys are saved in this browser only and are not put in backups or this HTML file. Direct browser calls expose keys to anyone using this browser, and a provider may block them with CORS. Use restricted, low-limit keys for personal testing. Answers are sent only when you tap Generate or Ask Gemini to judge.

4 · Backup and restore

Download a portable JSON backup before changing browsers or clearing browser data. It includes settings and all rounds (including any Gemini ratings), but never your API keys. Elo is recalculated from the restored rounds.

Merge appends rounds and may duplicate rounds if you import the same file twice. Replace first downloads nothing automatically, so keep your backup file safe.

5 · Local data controls

Your ratings, preferences, rounds, and API key are stored in this browser only. Browser storage is not a substitute for a backup.
