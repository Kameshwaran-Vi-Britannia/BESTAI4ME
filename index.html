BestAI4Me

Choose the use cases and how many rounds you want. Your connected AIs generate the answers, an AI judge panel picks the winner, and you can stop whenever you like.

Your choice. No forced extra rounds.

Set up this session

Pick a session length every time. One round is one realistic task prompt. The app stops at your chosen number; Stop ends it sooner.

AI answer makers

Choose at least two connected models. These models answer the same prompt, without seeing each other’s answers.

AI judges

Selected judges independently vote. You do not need to pick a winner.

How the panel decides: most judge votes wins. If votes tie, the higher panel-average score wins. If still tied, it is a draw and does not change Elo. Answer order is shuffled separately for each judge.

A model used as both answer maker and judge may recognize its own style or favor its own answer. Multiple profiles using the same underlying model are correlated, not fully independent. AI judges can also be wrong; scores are comparisons, not ground truth.

Each round uses API calls and may use your providers’ quota. Calls are made one at a time. A provider rate limit is shown; failed models or judges do not silently get counted as wins.

Your API connections

Add a profile for each model you want to test or use as a judge. You can reuse one API key across profiles with different model IDs. The Gemini model ID starts at gemini-3.8-flash; edit it or refresh the available models as Google updates its catalog.

API keys stay in this browser and are excluded from backups, but browser storage is not secure secret storage. Anyone with access to this browser or its page scripts may be able to read them. Use low-limit keys. Prompts and answers are sent to the selected providers when a session runs.

Backup and restore

Download your history before switching browsers. Backups keep rounds and connection settings, never keys.

Local data

History and settings are stored in this browser. Keep a downloaded backup somewhere safe.
